Already rooted with SSH?
git clone https://github.com/IrvingGuerra/lglow && cd lglow
./instalar.sh 192.168.1.50                # your TV's IP
ssh root@192.168.1.50 vi /var/lib/webosbrew/fullhomecustom/config.json
python3 tools/make-tiles.py 192.168.1.50  # tiles from your app icons

Undo everything: ./instalar.sh 192.168.1.50 --quitar and reboot the TV.

Compatibility

Made for the 2019 LGs.

What matters isn't the year on the box but how the TV's home is built. LGlow patches the QML home of webOS 4.5, so it fits the whole 2019 lineup with the full-screen home.

Not supported

2018

webOS 4.0

Rootable, but it never got the full-screen home LGlow is built on.

Supported

2019

webOS 4.5

With the full-screen home LG rolled out in December 2023 (firmware 05.40.09+): B9 and UM/SM/LM LCDs first, then C9 and E9.

Portable

2020–2024

webOS 5 to 9

Also a QML home, so the technique carries over with new patches. But the latest firmware blocks the root exploit.

Not supported

2025

webOS 10

The home was rewritten in Flutter. See webos10-homescreen-customization.

Tested on
LG 43LM5770PUA (2019, "webOS TV Lite"), webOS 4.10.2, firmware 05.40.97. Higher-end 2019 models may ship slightly different files: the installer checks every file it patches and changes nothing if yours differ, and the patches can be regenerated.
Requires
Root (faultmanager-autoroot + Homebrew Channel), SSH and a free TMDB key for "For you". Check your firmware on CanI.RootMy.TV.

FAQ

Good questions.

Can this brick my TV?

LGlow never writes to LG's read-only partitions: the new home is mounted on top of the stock one at boot. Rooting is a separate step with its own risks, so read the guide first. Use at your own risk.

How do I undo it?

Run ./instalar.sh <TV IP> --quitar and reboot. The stock home comes back exactly as it was.

Why do I see LG's home for the first ~45 seconds?

On webOS 4 nothing can run before root starts, about 42 seconds after a full power-on. With Quick Start+ on, the TV suspends instead of shutting down, so the new home stays between uses.

Is the TV interface in English?

Not yet: the on-screen text is in Spanish and "For you" ships with Mexico's streaming providers. You can change the provider ids for your country in config.json.

Does it include LG's code?

No. The repo only ships patches and new components. The installer copies the stock home from your own TV and patches it there.

Will it make apps open faster?

A little. You get more free memory and less swapping, but streaming apps are heavy web apps and the TV has 674 MB of RAM.
